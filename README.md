# FOCUS ⚡
وب‌سایت فارسی و راست‌چین برای برنامه‌ریزی درسی، مدیریت تکالیف و تمرین تمرکز.

## امکانات
- داشبورد XP و سطح کاربر
- مدیریت تکالیف و امتیاز برای تکمیل آن‌ها
- تایمر تمرکز با ثبت جلسه‌ها
- تقویم نمایشی با قالب فارسی/شمسی
- ثبت تاریخ امتحان‌ها
- پیشرفت و دستاوردها
- تم تیره/روشن و خروجی/بازیابی JSON
- صفحات مستقل و واکنش‌گرا برای موبایل و دسکتاپ

## انتشار با GitHub Pages
1. به Settings → Pages مخزن برو.
2. در بخش Build and deployment، گزینه **GitHub Actions** را به‌عنوان Source انتخاب کن.
3. شاخه `main` را با commit جدید به‌روزرسانی کن یا از Actions، گردش‌کار Deploy FOCUS to GitHub Pages را دستی اجرا کن.
4. پس از موفقیت workflow، آدرس سایت در خلاصه اجرای workflow نمایش داده می‌شود. معمولاً آدرس پروژه `https://brotex-dvplr.github.io/Focus/` خواهد بود.

فایل workflow در `.github/workflows/pages.yml` با هر push روی `main` اجرا می‌شود. GitHub Pages باید در تنظیمات مخزن فعال و Source آن روی GitHub Actions باشد.

## نکته مهم درباره داده‌ها
این نسخه فقط فرانت‌اند است و داده‌ها را در `localStorage` مرورگر نگه می‌دارد؛ ورود واقعی، همگام‌سازی ابری و پایگاه داده هنوز پیاده‌سازی نشده‌اند. برای انتشار عمومی، اطلاعات حساس را وارد نکنید.
